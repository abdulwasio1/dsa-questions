# 🧩 DSA Questions

A collection of my LeetCode problem-solving journey — solutions, approaches, and complexity analysis, written in Java and C++ as I work through Data Structures & Algorithms.

## 📌 About

This repo is my personal DSA practice log. Each solved problem includes:
- The problem description
- My approach / algorithm steps
- Time & space complexity
- Notes on limitations or planned optimizations (where relevant)

I'm using this both to track progress and as a quick-reference when revisiting patterns later.

## 🗂️ Structure

Problems are organized in one of two ways depending on when they were added:
- **Flat files** — `<number>. <Problem Name>.java` / `.cpp` for individual problems
- **Topic folders** — grouped by data structure or pattern (e.g. Linked List, Binary Tree)
